Fresh install / recovery
This installs the bootloader, partition table, OTA metadata and application at their intended addresses. The installer offers a full-erase option; selecting it deletes settings and OTA data in onboard flash. Files on the removable SD card are not targeted.

            
For regular updates on a working TypeN, use its own local Firmware Update page instead.

SUPPORT
Need a hand?
A few common fixes before trying again.

        

          
Installer says “Failed to install”
The page first checks the firmware and then automatically attempts the ESP32 download reset over USB. Use the P4 Type-C programming port, not the separate USB-OTG connector. If it fails, close other applications using that port and select Retry automatic connection. Open Connection details and save its log for troubleshooting. Hardware without an automatic-reset circuit may still require a manual recovery procedure.

          
The device is not listed in the serial port picker
Use the board’s Type-C programming connector (not the USB-OTG header), a USB data cable, and close other applications using the serial port. If Windows does not enumerate the USB-to-UART adapter, its driver may be missing.

          
Can I use Safari, Firefox, or an iPhone?
This installer is intended for desktop Chrome or Microsoft Edge with Web Serial enabled. Safari and iOS browsers do not provide the required USB serial access. Internet access is needed to load the installer and firmware.

          
Which P4 variant do I select?
Choose P4 Pico if your P4 uses a separately wired ESP32-C6 Zero over UART. Choose P4 Pico WiFi if the C6 is already on your P4 board and connected through SDIO. Both identify as ESP32-P4, so the browser cannot distinguish them automatically.

          
Do I flash the onboard WiFi C6 separately?
No. The external C6 slave package on this page is only for the separately wired ESP32-C6 Zero. It is not the onboard SDIO coprocessor firmware. Use the P4 Pico WiFi build for your onboard-C6 TypeN device.

          
Will installation delete my pictures?
The full USB install can reset information stored in the device's SPI flash, including settings and OTA state. The install does not write to the removable microSD card, where TypeN normally stores images and GIFs. Remove it during recovery if you prefer.

          
Can I update without wiping settings?
When TypeN is already working, use its built-in firmware update feature through the device's local Wi-Fi/web manager or SD update path. This USB flasher is intended for first-time setup and recovery.
